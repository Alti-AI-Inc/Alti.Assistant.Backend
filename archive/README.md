# Archive folder

This folder stores temporary, debug, or legacy files that are not part of the normal runtime path.

## Structure

- scratch/: one-off scratch scripts and sample data
- legacy-tests/: old or ad-hoc test scripts
- debug-scripts/: maintenance/debug utilities
- logs/: historical log files

These files are kept out of the main project root to reduce clutter. They can be deleted later if they are no longer needed.
